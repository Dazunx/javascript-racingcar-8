# 🚗 자동차 경주 게임

## 실행 방법
모든 테스트가 성공하면 `BUILD SUCCESSFUL` 이 출력됩니다.  
Java 21 환경에서 실행되어야 합니다.

---

## 입출력 예시
경주할 자동차 이름을 입력하세요. (쉼표로 구분)

```
pobi,woni,jun
```

시도할 횟수는 몇 회인가요?
```
5
```

실행 결과
```
pobi : –
woni : —
jun : –
```

- 차수별 실행 결과
```
pobi : --
woni : ----
jun : ---
```

- 단독 우승자 안내 문구
```
최종 우승자 : pobi
```
- 공동 우승자 안내 문구
```
최종 우승자 : pobi, jun
```
---

## 기능 목록
- 자동차 이름 입력받기
    - 쉼표 기준으로 구분
    - 5자 초과 시 예외 발생
- 시도 횟수 입력받기
    - 음수 또는 비정상 입력 시 예외 발생
- 자동차 생성
    - 이름과 위치 저장
    - 초기 위치 0으로 설정
- 전진 조건
    - 0~9 랜덤 숫자 생성
    - 4 이상이면 전진
- 매 라운드 결과 출력
    - `이름 : ---` 형태로 표시
- 우승자 판별
    - 최대 위치값과 동일한 자동차 출력
    - 여러 명이면 쉼표로 구분
- 예외 발생 시 `IllegalArgumentException` 던지고 종료
